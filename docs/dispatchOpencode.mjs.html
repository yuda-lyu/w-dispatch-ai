// dispatchOpencode.mjs — 以opencode CLI呼叫AI模型
//
// 【金鑰注入(2026-08-08於本機實測確認，非讀碼推論)】
//   OPENCODE_AUTH_CONTENT環境變數會「完全覆蓋」opencode的auth.json：
//   實測帶入無效key → `Error: Invalid API key.`(code=1、訊息在stderr、stdout空)；
//   帶入真實key → 正常回應。以env傳入「不會改寫」auth.json(實測md5前後一致)，
//   屬process層級，可與同時執行的其他專案並行而互不干擾。
//   註：OPENCODE_API_KEY在auth.json已有憑證時不生效，故一律走OPENCODE_AUTH_CONTENT。
//   原始碼依據(anomalyco/opencode dev, packages/opencode/src/auth/index.ts之Auth.all):
//   `if (process.env.OPENCODE_AUTH_CONTENT) return JSON.parse(...)`, 解析成功即整份取代, 不與auth.json合併;
//   空字串為falsy、非法JSON會落回讀auth.json。auth.json位於<XDG_DATA_HOME|~/.local/share>/opencode/。
//
// 【本轉接器只驗證過opencode v1(實測至1.18.32), v2尚未支援(2026-09-22查證, 2026-09-23補④)】
//   opencode已另發布v2(2026-09-23已至2.0.15, npm套件@opencode/cli, bin另含opencode2; 文件自成一棵樹
//   https://opencode.ai/v2/docs), 官方〈Migrate from V1〉明載「OpenCode 1 and OpenCode 2 both use the opencode
//   command and are no longer installed side by side by default... the V2 curl installer replaces the V1 binary」
//   ——即升級v2會取代同名執行檔。v1之npm套件opencode-ai(1.18.32)仍為latest且未標deprecated。
//   v2仍有`opencode run`(文件列為自動化用途)與`--agent`, 但至少四處與本轉接器之假設不同, 升級前須逐一實測:
//     ① 模型旗標: v2文件一律寫`--model provider/model`, 本轉接器用`-m`(v2是否保留為別名未驗證);
//     ② provider設定形狀: v2改為`providers.<id>.package`(單數provider→providers, npm→package並加aisdk:前綴),
//        與本轉接器經OPENCODE_CONFIG_CONTENT注入之v1形狀(provider.<id>.npm)不同;
//     ③ 金鑰注入: v2憑證走/connect與新憑證庫, OPENCODE_AUTH_CONTENT是否仍被讀取未驗證;
//     ④ 權限設定形狀: v2改為單一有序`permissions`陣列, 動作亦改名(bash→shell、task→subagent、write/patch→edit),
//        providers.mjs之OC_READONLY({edit:'deny', bash:'ask'})為v1形狀, 在v2不會被認得——唯讀鎖等同失效,
//        升v2前須以金絲雀(要求寫檔, 驗未落地)重驗防寫, 不可假設仍有效。
//   故本機若升v2, 請先以單一呼叫實測上述四項再調整本檔; 條目端可先以exe指定v1執行檔路徑過渡。
//
// 【cwd須同步PWD環境變數(2026-09-23實測後新增)】opencode run決定session目錄之原始碼為
//   `const root = Filesystem.resolve(process.env.PWD ?? process.cwd())`(packages/opencode/src/cli/cmd/run.ts),
//   即「繼承來的PWD優先於子進程真實cwd」。Git Bash與Linux/macOS之shell皆會設PWD, 故呼叫端給opt.cwd而
//   父進程PWD指向他處時, opencode會在父進程目錄作業: 讀相對路徑落空(回NOTFOUND且ok:true, 靜默失敗),
//   允許寫檔時檔案落在父進程目錄(本專案曾因此於根目錄留下金絲雀孤兒檔, 當時誤判為「以git根目錄為準」)。
//   實測(cwd指向探針目錄, 父PWD=專案根): 不處理→working directory為專案根、讀MARKER.txt失敗;
//   注入PWD=cwd→正確; 帶--dir亦正確。採注入PWD: 不動命令列(與--attach等extraArgs無衝突), 語意即shell
//   於該目錄啟動程式時之環境; 且以本函數之值蓋過opt.env之PWD(呼叫端常整份展開process.env, 若讓其覆寫
//   則缺陷靜默回歸)。claude與codex以同組探針實測皆遵循spawn cwd, 不受影響, 故只在本轉接器處理。
//
// 【Zen免費層閘門與config注入(2026-09-18實測)】opencode自2026-09-17起限制免費模型只准在opencode本體內使用
//   (403 FreeTierError: free tier can only be used from within OpenCode)。CLI本身可通, 但經OPENCODE_CONFIG_CONTENT
//   注入之設定若把bash工具deny掉(permission.bash:'deny'、tools.bash:false、agent覆寫deny), 請求之工具清單
//   少了bash即被判非opencode而403; 改permission.bash:'ask'則通過, 且非互動run下ask自動拒絕, 仍為機械防寫。
//   詳見providers.mjs檔頭【Zen免費層閘門】與OC_READONLY常數。
//
// 【Zen免費層429限流時run不會結束(2026-09-23實測, 1.18.32)】REST探測0.7s即回429 FreeUsageLimitError
//   (Rate limit exceeded), 但`opencode run`收到同一錯誤後不退出: 預設stderr只有session標頭, 直到呼叫端逾時;
//   帶--print-logs --log-level DEBUG可見`stream error ... AI_APICallError: Rate limit exceeded`, 其後再無輸出。
//   不經本套件直接跑原始CLI亦同, 非本轉接器所致。對本套件之意義: 此情形以TIMEOUT回報(errorType 'timeout'),
//   dispatchAiFallback內建之TIMEOUT冷卻觸發可涵蓋, 但每次嘗試都耗滿timeoutMs——免費oc:條目宜以
//   resolveProviders之patch給較短timeoutMs; 需在stderr看到字樣(供coolDetect)時於extraArgs加
//   --print-logs --log-level ERROR。
//
// 【不讀auth.json之匿名呼叫: useStoredAuth:false(2026-09-17實測後新增)】
//   未注入金鑰時opencode會自動沿用auth.json之登入; 該帳號工作區若未開某免費模型(如union-alpha),
//   就回`Error: Model is disabled`, 而同一模型在「無auth.json」之機器上匿名可用——結果隨執行機器而異。
//   useStoredAuth:false時注入OPENCODE_AUTH_CONTENT='{}'(空憑證), 令本次不讀auth.json而以匿名免費存取。
//   實測(以XDG_DATA_HOME指向內含opencode金鑰之暫存auth.json): 不帶key→Model is disabled;
//   加'{}'→7.0s成功; 改注入''→仍Model is disabled(空字串無效, 故不可讓呼叫端自填); auth.json前後md5一致。
//   同時給key與provider時金鑰注入本就整份取代auth.json, 此旗標不再作用。
//   風險備忘: 原始碼Auth.set會以Auth.all()(即注入內容)為底寫回auth.json, 僅於OAuth權杖刷新等寫入時發生;
//   api型金鑰與空憑證皆無刷新, 實測未觸發。
//
// 【provider與model必須配對】不同provider的金鑰不可互換：
//   實測把agnes-ai的金鑰用於opencode/...模型 → `Invalid API key`。
//   故呼叫端傳入的key／provider／model須為同一組。
//
// 【OpenCode Go(月費訂閱)——provider opencode-go(2026-11-03 da65, Gitea #65; 全貌見providers.mjs檔頭【OpenCode Go】段)】
//   同一把Console工作區金鑰(前綴oc_sk_)有兩個provider id: model `opencode/<id>`(provider opencode)走免費池或按量餘額; model `opencode-go/<id>`(provider opencode-go)走Go月費額度。
//   本轉接器不必改動即支援Go: opt.provider給 'opencode-go' 時依上段注入 OPENCODE_AUTH_CONTENT={"opencode-go":{type:'api',key}}(以opt.provider為鍵), model給 'opencode-go/<id>';
//   key／provider／model仍須為同一組(見下【provider與model必須配對】)。Go走opencode CLI本身(官方支援之客戶端, 自帶x-opencode-session標頭);
//   直打Go之REST基底須自帶該標頭(缺則400 MissingSessionID), 故本套件只收CLI類Go條目(providers.mjs之ocgo:)。
//   錯誤字樣對照〔本機實測 2026-11-03, opencode 1.19.5〕:
//     未訂閱Go之金鑰 → stderr「Upstream request failed: An active OpenCode Go subscription is required to use Go models.」, opencode內部重試約77秒才exit 1(errorType 'exec');
//     id不在Go型錄 → 「ProviderModelNotFoundError: Model not found: opencode-go/<id>.」, 約1.7秒即exit 1;
//     「Free usage limit reached…subscribe to OpenCode Go to keep going」＝ provider opencode之免費池用盡, 不影響opencode-go/之模型(同一分鐘內opencode-go/beam-free 6.1s成功); 此時run不結束(見上【429限流時run不會結束】), 以TIMEOUT回報。
//   〔issue #65提出端自述, 本機未重現〕隱私開關未開: 「This Go model requires Global regions. Select Global in your workspace's Privacy settings to use it.」(DeepSeek)、
//     「This Go model trains on request data. Allow paid endpoints that train on request data in your workspace's Privacy settings to use it.」(Muse／Iceman Contributor);
//     付費id錯用opencode/前綴 → 「Upstream request failed: Model access is disabled」; 以OPENCODE_CONFIG_CONTENT補定義Go專屬id後 → 「Model is unavailable」。
//   Go額度到頂時run之行為與字樣未查明(免費池到頂時run不結束; Go是否同樣不返回, 本機與提出端皆未撞到), 呼叫端宜以timeoutMs封頂, 並可先以opencodeGoUsage(src/opencodeGoUsage.mjs)查三視窗(該端點官方文件未載, 為實測所得); 經dispatchAiFallback時預設已由quotaGate(src/goQuotaGate.mjs)於用量≥95%時略過該把金鑰。
//
// 【spawnGate: 機器級守門(預設啟用, 2026-11-04 Gitea #67)】每次spawn前查機器上opencode.exe行程數(預設上限 max(1, 核心數-1))與RAM(已用>0.85)、CPU(>0.90), 達上限即等(每10秒再查, 等逾10分鐘放行), 計數或取樣失敗亦放行;
//   等待不計入timeoutMs; spawnGate:false關閉; 預設只守exe為真的opencode(假CLI與包裝腳本不守, 明給spawnGate才守); 詳見cliSpawnGate.mjs檔頭(含opencode.exe單次占約1.1核心之實測、成本量測、跨行程預約票)。
//   實際呼叫由runExecCli統一處理(四家共用), 本轉接器只傳spawnGateKind: 'opencode'。
//   另有放行最小間隔minGapMs(預設1500ms, 同行程併發呼叫之放行至少相隔此時距, 避免多個實例同瞬間啟動而搶本機資料庫; false關閉)與暫時性錯誤重試(失敗訊息含`database is locked`、非逾時且耗時<15秒者多重試一次,
//   不佔maxRetries次數、重試前再過守門、attempts照實累計, 見runExecCli.mjs檔頭【暫時性錯誤重試】; 2026-11-05 Gitea #85)。
//   隱私前提: Go繼承工作區Settings›Privacy——預設擋「以請求資料訓練之付費端點」且地區限歐美; DeepSeek須選Global、Muse／Iceman Contributor須開train-on-data開關; iceman與muse會以提示詞訓練模型, 敏感內容勿走。
//
// 【單次回應輸出上限: 預設注入OPENCODE_EXPERIMENTAL_OUTPUT_TOKEN_MAX(2026-11-04 da78, Gitea #78; 規則細節與證據見outputTokenMax.mjs檔頭、帳本R-OCGO-4)】
//   opencode以min(型錄limit.output, 環境變數或預設32000)為請求之max_tokens——「32,000」是CLI端預設而非閘道限制(假OpenAI相容服務攔截請求實測)。
//   推理模型之reasoning與output共用此額度: 長提示詞配高檔位(--variant high)時reasoning可把32000吃光, 正文為空或被截,
//   而CLI回ok:true、stdout空、離開碼0、stderr僅標頭、opencode日誌無ERROR(Go模型glm-5.3-flash實測: 3萬字元提示詞, high, 預設上限 → finish=length、reasoning恰32000、output 0)。
//   本轉接器預設把上限調為DEFAULT_OUTPUT_TOKEN_MAX(見outputTokenMax.mjs); opt.outputTokenMax可覆寫; 呼叫端環境(opt.env或process.env)已設有效值者原樣保留。
//
// 【截斷偵測(opt.detectTruncation, 預設false; 2026-11-04 da78)】預設格式下回應「為何結束」不可見; `--format json`事件流之step_finish事件帶終止原因(reason)與token。
//   detectTruncation:true時本轉接器加`--format json`, 解析事件流後把stdout/stderr還原為預設格式(逐案比對與預設路徑之stdout逐位元相同; stderr不含`> agent · model`標頭與工具進度行,
//   錯誤事件還原為`Error: 訊息`), 並於最後一步之reason為length時回報截斷: 失敗(errorType 'incomplete', error以INCOMPLETE_RESPONSE開頭, 結果帶truncated:true、finishReason、tokens),
//   與REST轉接器同一規則(checkTruncation.mjs); 確定性截斷不驗證、不重試(runExecCli), dispatchAiFallback依truncated旗標整組跳過、換下一個條目。
//   opt.acceptTruncated:true可放行length且有可見輸出之結果(標truncated:true)。未開detectTruncation者行為與修前逐位元相同(預設格式、不判截斷)。
//   呼叫端自給`--format json`(extraArgs)者視為要原始事件: stdout不改寫, 但仍判截斷並加欄位。
//
// 【失敗原因帶回與日誌對時擷取(opt.opencodeLog, 2026-11-08 da110, Gitea #110)】失敗(離開碼非零、逾時)時error帶stderr尾段並加errorDetail(共用邏輯在runExecCli.mjs／failureDiag.mjs);
//   opencode另在失敗後讀其日誌檔一次, 取失敗時刻±60秒內providerID／modelID相符之ERROR行的原因附入errorDetail.upstream並把簡短分類放進error文字(實查日誌格式與位置見opencodeUpstream.mjs檔頭)。
//   本機實查(opencode 1.19.5): 不存在之model令run離開碼1, stderr為帶ANSI色碼之`Error: {pretty JSON UnknownError「Unexpected server error. Check server logs for details.」, ref}`——通稱字樣, 真因只在日誌;
//   detectTruncation(--format json)時錯誤改為stdout之error事件, stderr空, 本轉接器還原為`Error: 訊息`後交runExecCli取尾段(reshapeResult以diagStderr／diagStdout傳遞, runExecCli取用後移除)。
//   另: 成功結果之finish取自事件流最後一步之終止原因(僅detectTruncation為true時可得, 否則由runExecCli補'unknown')。
//
// 【第三方provider須另給config(2026-08-09於本機實測確認)】
//   opencode僅內建自家provider，第三方(例如agnes-ai)未定義於設定檔時，
//   只注入金鑰仍無法使用：實測`opencode models`不列出該provider之模型，
//   直接指定模型則回`UnknownError／Unexpected server error`。
//   OPENCODE_CONFIG_CONTENT環境變數可逐次注入設定內容，補上provider定義後
//   `opencode models`即列出agnes-ai/agnes-2.0-flash且可正常對話，
//   與OPENCODE_AUTH_CONTENT同為process層級，不改寫使用者設定檔。


//預設值
let DEFAULT_EXE = 'opencode'
let DEFAULT_AGENT = 'build'


//本轉接器自用之設定鍵, 其餘鍵一律原樣轉傳execCli(acceptTruncated由runExecCli讀取, 見其檔頭; reshapeResult為本轉接器內部傳給runExecCli之接縫, 呼叫端給的一律剔除)
let OWN_KEYS = ['exe', 'model', 'key', 'provider', 'useStoredAuth', 'agent', 'config', 'extraArgs', 'input', 'env', 'outputTokenMax', 'detectTruncation', 'reshapeResult', 'opencodeLog', 'diagSecrets']


//accumulate上限(字元), 偵測截斷時累積子進程stdout全文以供解析, 超出部分不再累積
let ACC_MAX = 32 * 1024 * 1024


/**
 * 由命令列旗標陣列取`--format`之值(支援`--format json`與`--format=json`，取最後一個)
 *
 * @param {Array} args 輸入旗標字串陣列
 * @returns {String} 回傳旗標值字串，未給為空字串
 */
function getFormatArg(args) {
    let fmt = ''
    for (let i = 0; i < args.length; i++) {
        let a = args[i]
        if (a === '--format' && i + 1 < args.length) {
            fmt = args[i + 1]
        }
        else if (a.startsWith('--format=')) {
            fmt = a.slice(9)
        }
    }
    return fmt
}


/**
 * 以opencode CLI呼叫AI模型
 *
 * 特點：
 * prompt一律走stdin而非位置參數，因摘要內文可達數萬字，當命令列參數會spawn ENAMETOOLONG，
 * 而opencode run未帶位置message時即從stdin讀取；
 * 同時給予key與provider時，以OPENCODE_AUTH_CONTENT環境變數逐次注入金鑰，
 * 該注入僅作用於當次子進程且不改寫auth.json，故可多把金鑰輪替並與其他程序並行；
 * 未給key或provider時沿用CLI既有登入狀態(auth.json)，useStoredAuth為false則改以匿名存取；
 * 使用opencode未內建之第三方provider時，須另以config給予其provider定義；
 * 本函數不會reject，一律以結果物件之ok與error欄位回報成敗
 *
 * @param {String} prompt 輸入提示詞字串，一律以stdin傳入子進程
 * @param {Object} [opt={}] 輸入設定物件，預設{}
 * @param {String} [opt.exe='opencode'] 輸入opencode執行檔名稱或絕對路徑字串，給予名稱時由execCli自系統PATH解析(.cmd/.bat只給檔名時依cmd.exe語意先搜cwd再搜PATH，cwd不可信時請給絕對路徑)，預設'opencode'
 * @param {String} [opt.model=''] 輸入模型ID字串，例如'opencode/beam-free'，預設''代表不帶`-m`旗標
 * @param {String} [opt.key=''] 輸入該provider之API key字串，須與provider同時給予才會注入，預設''代表沿用CLI既有登入狀態
 * @param {String} [opt.provider=''] 輸入key所屬provider名稱字串，須與key同時給予才會注入，且須與model為同一組，預設''
 * @param {Boolean} [opt.useStoredAuth=true] 輸入未注入金鑰時是否沿用本機auth.json之登入布林值，false代表注入空憑證令本次以匿名存取(適用opencode之免費模型，避免結果隨本機登入帳號而異)；已同時給key與provider時不作用，預設true
 * @param {Object|String} [opt.config=null] 輸入opencode設定內容物件或其JSON字串，將以OPENCODE_CONFIG_CONTENT逐次注入，供補上第三方provider之定義，預設null代表沿用使用者既有設定檔
 * @param {String} [opt.agent='build'] 輸入opencode代理名稱字串，預設'build'
 * @param {Array} [opt.extraArgs=[]] 輸入額外命令列旗標字串陣列，將接於固定旗標之後，預設[]
 * @param {Object} [opt.env=undefined] 輸入本次調用額外注入之環境變數物件，同時給予key與provider時會再併入OPENCODE_AUTH_CONTENT，預設undefined
 * @param {Number|String} [opt.outputTokenMax=128000] 輸入單次回應輸出上限(token)正整數(數字或數字字串)，注入子進程環境OPENCODE_EXPERIMENTAL_OUTPUT_TOKEN_MAX(reasoning與output合計，實際上限取此值與模型型錄limit.output之較小者；opencode自身預設32000)；給了有效值即蓋過呼叫端環境；未給或無效(0、負數、小數、非數字、Infinity、布林)時，呼叫端環境(opt.env或process.env)已設有效值者原樣保留，否則用套件預設128000；調高會使可用輸入約減少同量，見outputTokenMax.mjs檔頭，預設128000
 * @param {Boolean} [opt.detectTruncation=false] 輸入是否偵測輸出被上限截斷布林值，true代表改用`--format json`事件流並還原輸出，最後一步終止原因為length時回報失敗(errorType 'incomplete'、truncated:true、finishReason、tokens)且不重試，見檔頭【截斷偵測】，預設false代表不偵測(行為同修前)
 * @param {Boolean} [opt.acceptTruncated=false] 輸入是否接受被截斷(finish為length)但有可見輸出之結果布林值，true代表放行(照常交validate)並標truncated:true，僅detectTruncation為true時有作用，預設false
 * @param {Number} [opt.timeoutMs=300000] 輸入逾時毫秒正整數，逾時將強制關閉子進程及其子孫程序，全套件統一預設300000
 * @param {String} [opt.cwd=process.cwd()] 輸入子進程工作目錄字串，預設process.cwd()；其絕對路徑並同步注入環境變數PWD(opencode以繼承之PWD優先於真實cwd決定session目錄，見檔頭)，呼叫端env內之PWD會被覆寫
 * @param {String|Function} [opt.validate=undefined] 輸入stdout驗證規則字串或自訂驗證函數，規則字串支援'nonempty'、'json'、'min:100'，多規則可用逗號串接，自訂函數可回傳Promise(以resolve值判定，與子進程共用該次嘗試之timeoutMs)，拋錯或reject視同驗證失敗(OUTPUT_VALIDATION_FAILED，stderr前綴'validate threw: 訊息')，逾時亦同(前綴'validate timed out: did not settle within Ns')，durationMs含驗證時間，預設undefined代表不驗證
 * @param {Number} [opt.maxRetries=0] 輸入失敗後最大重試次數非負整數，預設0；另有不佔此次數之暫時性錯誤重試(失敗訊息含`database is locked`、非逾時且耗時<15秒者多重試一次，每次呼叫至多一次，attempts照實累計)
 * @param {Boolean|Object} [opt.spawnGate=undefined] 輸入spawn前之機器級守門設定：未給為預設(opencode預設啟用：機器上opencode.exe數達max(1, 核心數-1)、RAM已用>0.85或CPU>0.90即等，每10秒再查，等逾10分鐘或計數取樣失敗即放行；且只守exe為真的opencode)，false關閉，true取預設且不受exe比對限制，物件可覆寫maxCli、ramUsedMax、cpuMax、minGapMs(放行最小間隔，預設1500毫秒，false關閉)、pollMs、gateWaitMaxMs等；等待不計入timeoutMs，見cliSpawnGate.mjs檔頭，預設undefined
 * @param {String|Boolean} [opt.opencodeLog=undefined] 輸入opencode日誌檔路徑字串(覆寫預設)或false(不讀)，失敗(離開碼非零、訊號結束、逾時)時才讀一次(檔尾至多2MiB)，取失敗時刻前後各60秒內providerID／modelID與model(須為`provider/model`形式)相符之level=ERROR行的原因，遮蔽後附入errorDetail.upstream並把簡短分類放進error文字(如`Exit code 1 [overloaded]: …`)；找不到、檔案不存在或不可讀皆略過、不影響成敗、不拋錯；預設undefined代表依平台推得`<XDG_DATA_HOME(opt.env優先於process.env)或~/.local/share>/opencode/log/opencode.log`(找不到時退用同資料夾最新之*.log)，見opencodeUpstream.mjs檔頭
 * @returns {Promise} 回傳Promise，resolve回傳結果物件，內含ok(是否成功布林值)、stdout(標準輸出字串)、stderr(標準錯誤字串，自訂validate拋錯時前綴'validate threw: 訊息')、code(離開碼，子進程未能啟動時為null)、error(錯誤訊息字串，成功時為空字串)、errorType(僅失敗時，機器可讀錯誤類別字串，子進程未能啟動為'spawn'，一覽見getErrorType.mjs檔頭)、durationMs(耗時毫秒)、pid(子進程pid，未能啟動時為undefined)、attempts(實際嘗試次數)；detectTruncation為true且最後一步被輸出上限截斷時另帶truncated(true)、finishReason('length')、tokens(最後一步之token用量物件{ total, input, output, reasoning, cache })，未截斷者不加此三欄；失敗(離開碼非零、訊號結束、逾時)時error為`Exit code N[ [分類]]: <stderr尾段>`(尾段至多300字元，已遮蔽金鑰權杖；stderr空時Exit code退用stdout尾段)並另帶errorDetail({ exitCode(數字或null), stderrTail, stdoutTail(僅stdout非空), upstream(僅日誌擷取到時) })；成功時另帶finish(終止原因簡值：detectTruncation為true時取最後一步之終止原因，如'stop'、'length'，否則'unknown')與outputChars(stdout字元數)；incomplete(截斷)失敗結果不加errorDetail、finish、outputChars；本函數不會reject
 * @example
 * //need opencode cli in system PATH
 *
 * import dispatchOpencode from './src/dispatchOpencode.mjs'
 *
 * let test = async () => {
 *
 *     //沿用CLI既有登入狀態(auth.json)
 *     let r1 = await dispatchOpencode('請只回覆兩個字：完成', { model: 'opencode/beam-free' })
 *     console.log(r1.ok, r1.stdout.includes('完成'))
 *     // => true true
 *
 *     //不沿用本機登入之匿名存取(opencode自家免費模型建議如此, 見檔頭【Zen免費層閘門】)
 *     let r2 = await dispatchOpencode('請只回覆兩個字：完成', {
 *         model: 'opencode/beam-free',
 *         useStoredAuth: false,
 *     })
 *     console.log(r2.ok)
 *     // => true
 *
 *     //opencode未內建之第三方provider, 須另以config給予其定義
 *     let r3 = await dispatchOpencode('請只回覆兩個字：完成', {
 *         model: 'agnes-ai/agnes-2.0-flash',
 *         provider: 'agnes-ai',
 *         key: 'sk-xxxxxx',
 *         config: {
 *             provider: {
 *                 'agnes-ai': {
 *                     npm: '@ai-sdk/openai-compatible',
 *                     name: 'Agnes',
 *                     options: { baseURL: 'https://apihub.agnes-ai.com/v1' },
 *                     models: { 'agnes-2.0-flash': { name: 'Agnes 2.0 Flash' } },
 *                 },
 *             },
 *         },
 *     })
 *     console.log(r3.ok)
 *     // => true
 *
 * }
 * await test()
 *     .catch((err) => {
 *         console.log(err)
 *     })
 *
 */
async function dispatchOpencode(prompt, opt = {}) {

    //check prompt, 不reject故以錯誤結果物件回報
    prompt = asText(prompt) //String包裝物件取其原始字串(stdin只收原始字串, 空包裝不得繞過非空檢核); 判型不執行使用者程式碼(已撤銷之Proxy等回空字串)
    if (prompt === '') {
        return getErrorResult('prompt must be a non-empty string')
    }

    //exe, 無效回退預設'opencode', 由execCli自系統PATH解析實體路徑
    let exe = get(opt, 'exe', null)
    if (!isestr(exe)) {
        exe = DEFAULT_EXE
    }

    //model, 無效時整段`-m`旗標不出現, 由CLI自行決定使用模型
    let model = get(opt, 'model', null)

    //agent, 無效回退預設'build'
    let agent = get(opt, 'agent', null)
    if (!isestr(agent)) {
        agent = DEFAULT_AGENT
    }

    //extraArgs
    let extraArgs = get(opt, 'extraArgs', null)

    //截斷偵測(detectTruncation, 預設false): 預設格式下終止原因不可見, 須改用`--format json`事件流(見parseOpencodeEvents.mjs檔頭);
    //呼叫端未自給--format時由本轉接器加上並把輸出還原為預設格式(rewrite); 呼叫端自給json者視為要原始事件, 不改寫輸出只加判定欄位; 自給其他格式者無從偵測
    let detectTruncation = get(opt, 'detectTruncation', null) === true
    let fmtUser = getFormatArg(getCliArgs(extraArgs))
    let rewrite = detectTruncation && fmtUser === ''
    let detect = rewrite || (detectTruncation && fmtUser === 'json')

    //args
    let args = getCliArgs(
        'run',
        ['--agent', agent],
        isestr(model) ? ['-m', model] : [],
        rewrite ? ['--format', 'json'] : [],
        extraArgs,
    )

    //env, 呼叫端物件不可讀(拋錯之getter、已撤銷之Proxy)以params回報, 不reject; 可讀者取物化之淺層副本(只讀一次, 與另三家經runExecCli同一helper); 非物件回退undefined代表不覆寫任何變數
    let renv = readCallerObj(get(opt, 'env', null), 'env')
    if (!renv.ok) {
        return getErrorResult(renv.msg)
    }
    let env = renv.value
    if (!isobj(env)) {
        env = undefined
    }

    //config有效才注入, 否則沿用使用者既有設定檔, 物件則序列化為JSON字串;
    //不可序列化(BigInt、循環參照、toJSON或getter拋錯)或不可判型(已撤銷之Proxy)以錯誤結果物件回報, 不reject(呼叫無法開始, 與金鑰無關故為params)
    let config = get(opt, 'config', null)
    try {
        if (isobj(config)) {
            config = JSON.stringify(config)
        }
    }
    catch (err) {
        return getErrorResult(`config is not JSON-serializable: ${errMsg(err)}`) //errMsg對拋出null、已撤銷之Proxy等不再拋錯
    }
    if (isestr(config)) {
        env = {
            ...env,
            OPENCODE_CONFIG_CONTENT: config,
        }
    }

    //key與provider皆有效才注入, 否則沿用auth.json既有登入狀態(單金鑰時即為原有行為);
    //useStoredAuth為false且未注入金鑰時, 注入'{}'令opencode本次不讀auth.json(匿名, 見檔頭)
    let key = get(opt, 'key', null)
    let provider = get(opt, 'provider', null)
    let useStoredAuth = get(opt, 'useStoredAuth', null) !== false
    if (isestr(key) && isestr(provider)) {
        env = {
            ...env,
            OPENCODE_AUTH_CONTENT: JSON.stringify({ [provider]: { type: 'api', key } }),
        }
    }
    else if (!useStoredAuth) {
        env = {
            ...env,
            OPENCODE_AUTH_CONTENT: '{}',
        }
    }

    //PWD同步為有效cwd之絕對路徑(有給cwd則解析之, 否則process.cwd(), 與execCli之spawn cwd同源),
    //以本值蓋過呼叫端env之PWD——opencode以繼承之PWD優先於真實cwd決定session目錄(見檔頭【cwd須同步PWD】)
    let cwdEff = get(opt, 'cwd', null)
    cwdEff = isestr(cwdEff) ? path.resolve(cwdEff) : process.cwd()
    env = {
        ...env,
        PWD: cwdEff,
    }

    //單次回應輸出上限: opencode預設以min(型錄limit.output, 32000)為max_tokens, 長提示詞配高檔位時reasoning把32000吃光、正文為空(見outputTokenMax.mjs檔頭);
    //優先序 opt.outputTokenMax > 呼叫端環境已設之有效值(opt.env或process.env, 保留不動) > 套件預設
    env = applyOutputTokenMax(env, get(opt, 'outputTokenMax', null)).env

    //timeoutMs, 無效回退全套件統一預設(dfTimeoutMs=300000), 各轉接器一致令呼叫方無須記多套數字
    let timeoutMs = castPintOr(get(opt, 'timeoutMs', null), dfTimeoutMs)

    //optCli, 剔除本轉接器自用鍵後原樣轉傳, 令呼叫端可用execCli全部設定(例如onStdout、maxBuffer)
    let optCli = omit(opt, OWN_KEYS)

    //截斷偵測之接縫: onStdout累積事件流全文(失敗結果之stdout被execCli裁到500字元, 事件流會被截斷, 故須自行累積), reshapeResult於每次execCli結果出來後還原輸出並讀出終止原因
    if (detect) {
        let acc = ''
        let userOnStdout = get(optCli, 'onStdout', null)
        optCli.onStdout = (str) => {
            if (acc.length < ACC_MAX) {
                acc += str
            }
            if (isfun(userOnStdout)) {
                userOnStdout(str) //呼叫端回調拋錯由execCli的callUser承接
            }
        }
        optCli.reshapeResult = (r) => {
            let raw = acc !== '' ? acc : String(get(r, 'stdout', '') || '')
            acc = '' //下一次嘗試重新累積
            let p = parseOpencodeEvents(raw, { lastSessionOnly: true }) //重試各開新session, 只取本次嘗試
            if (!p.hasEvents) {
                return r
            }
            let ok = get(r, 'ok', false) === true
            let extra = (ok && p.truncated) ? { truncated: true, finishReason: p.finishReason, tokens: p.tokens } : {}

            //成功結果之終止原因(最後一步之reason; 事件流才取得到): finish由runExecCli補outputChars, 已有finish者不覆寫(見failureDiag.mjs)
            let fin = ok ? { finish: finishOf(p.finishReason) } : {}
            if (!rewrite) {

                //呼叫端自給--format json(要原始事件): stdout不動; 失敗時錯誤事件還原之`Error: 訊息`仍作為診斷尾段來源(diagStderr, 由runExecCli取用後移除)
                if (ok) {
                    return { ...r, ...extra, ...fin }
                }
                return p.stderr !== '' ? { ...r, diagStderr: `${get(r, 'stderr', '') || ''}${p.stderr}` } : r
            }
            if (ok) {
                return { ...r, stdout: p.stdout, ...extra, ...fin }
            }

            //失敗: 還原stdout(裁500同execCli)與stderr(原stderr後接錯誤事件還原之`Error: 訊息`, 裁1000同execCli之離開碼失敗);
            //未裁切之還原全文另以diagStderr／diagStdout交runExecCli取診斷尾段(裁切後之欄位只留前段, 錯誤行常在末端; 取用後自結果移除);
            //無錯誤事件可還原時不給diagStderr(由runExecCli取擷取到之原始stderr尾端)
            let seFull = `${get(r, 'stderr', '') || ''}${p.stderr}`
            return {
                ...r,
                stdout: strTruncate(p.stdout, 500, optTruncate),
                stderr: strTruncate(seFull, 1000, optTruncate),
                ...(p.stderr !== '' ? { diagStderr: seFull } : {}),
                diagStdout: p.stdout,
            }
        }
    }

    //execCli(經runExecCli: 自訂validate拋錯視同驗證失敗、失敗結果補上機器可讀之errorType, 見runExecCli.mjs), prompt一律走stdin
    //spawnGate(使用端給之守門設定, 原樣留在optCli)與spawnGateKind交runExecCli於每次spawn前守門(見cliSpawnGate.mjs; opencode預設啟用)
    //diagSecrets: 本次注入之金鑰, 失敗診斷尾段(errorDetail、error文字)據以精確遮蔽(見failureDiag.mjs)
    let r = await runExecCli(exe, args, {
        ...optCli,
        input: prompt,
        env,
        timeoutMs,
        spawnGateKind: 'opencode',
        diagSecrets: isestr(key) ? [key] : [],
    })

    //失敗(exec或逾時, 即runExecCli已加errorDetail者)時對時擷取opencode日誌中的上游原因(見opencodeUpstream.mjs): 只讀一次、讀檔失敗或無相符不影響結果、永不拋錯;
    //opencodeLog為false關閉, 字串為日誌檔路徑(覆寫預設), 未給依平台推得
    let logOpt = get(opt, 'opencodeLog', null)
    if (r.ok !== true && isobj(r.errorDetail) && logOpt !== false) {
        let up = await readOpencodeUpstream({
            model,
            tFailMs: Date.now(),
            durationMs: r.durationMs,
            file: isestr(logOpt) ? logOpt : '',
            env,
            secrets: isestr(key) ? [key] : [],
        })
        r = addUpstream(r, up)
    }
    return r
}
