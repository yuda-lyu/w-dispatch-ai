## R-OCGO-1 Go 條目(CLI 類 `ocgo:`)

- 規則:①Go 條目一律 `kind:'opencode'`、`provider:'opencode-go'`、`model:'opencode-go/<id>'`、id＝`ocgo:`＋model(provider 與 model 前綴同名);②金鑰變數 **`OPENCODE_GO_KEYS`**,不沿用 `OPENCODE_KEYS`(Go 訂閱綁工作區;本機實測同一份 `OPENCODE_KEYS` 內有未訂閱者,打 Go 模型 77 秒才失敗,沿用會令全取遞補對每把未訂閱金鑰空耗);③須金鑰(不匿名,無 `useStoredAuth:false`);④防寫同其餘 `oc:` 條目(`OC_READONLY`:`edit:deny`＋`bash:ask`,不 deny bash);⑤檔位逐條依 CLI 型錄(`opencode models opencode-go --verbose`)核對:有 `high` 取 `high`,**無 `high` 取最高檔(qwen3.8-flash:`xhigh`)——偏離使用者 2026-09-30「思考強度一律 high」,為目錄內唯一例外,測試以 model 逐條列出,待使用者裁示**,無檔位者不帶;⑥**不收 REST 類 Go 條目**(Go 基底必帶 `x-opencode-session`,官方限 coding agent,一般 REST 是否允許官方未載);⑦位置:緊接最後一條 `oc:opencode/*` 之後、`agy:` 之前;不以請求資料訓練者在前、會訓練者(iceman、muse)殿後;⑧條目註解逐項標〔本機實測〕／〔提出端〕／〔CLI型錄〕;**實測不到者標「本機未實測」,不得寫成已驗證**;隱私前提(Global 地區、train-on-data 開關、訓練與保留、限地區)逐條載明;⑨**連網守門** `test/api-providersOpencodeGo.test.mjs`:目錄 Go 條目之 model ⊆ 匿名 `https://opencode.ai/inference/go/v1/models`;環境不足(離線、HTTP 非 200、非 JSON、清單為空)`this.skip()` 並印原因,不得當成通過;紅燈＝型錄已不列,依⑩處理;⑩**收錄與下架判準**:收錄＝公開型錄有列(守門)＋CLI 型錄欄位＋實呼簡答;免費期模型再做推理題、read 工具、寫檔金絲雀(須被 `OC_READONLY` 擋下)、脈絡長度;付費模型本機實測受任務授權限制(da65 最多 1 次簡答),未測者標「本機未實測」可收(opt-in 變數保護:缺 `OPENCODE_GO_KEYS` 即 skipped);下架＝公開型錄與 CLI 型錄皆不列且依條目呼叫回 `ProviderModelNotFoundError`(本機實測不存在之 id 約 1.7 秒回此錯;**下架判準為推定**,尚無實例).

## R-OCGO-2 用量查詢 `opencodeGoUsage`

- 規則:①簽名 `opencodeGoUsage({ key, baseURL = 'https://opencode.ai/inference/go/v1', timeoutMs = 10000 })`,`src/opencodeGoUsage.mjs`,於 `WDispatchAi` 具名匯出(鍵 33 → 34);②只送 `GET <baseURL>/usage`＋`Authorization: Bearer <key>`,無本文,不帶 `x-api-key`(端點只認 Bearer);③**端點官方文件未載,為實測所得、非官方承諾**,檔頭、README、JSDoc 皆須標明;形狀逐項驗證(`usage` 須為物件;三視窗缺漏或 `status` 非 `'ok'`／`'rate-limited'` 者列入 `unknownStatus`),形狀不符回 `errorType:'parse'`,不猜測、不補預設;④回傳三視窗**原值**(`usage.rolling|weekly|monthly`,額外欄位保留,`percent` 不轉型不換算),不換算金額;⑤`limited`＝任一視窗 `status==='rate-limited'`;`limitedWindows`;`unknownStatus`;**`available`＝三視窗皆 `'ok'`(未知狀態不得當正常)**,判斷請用 `available` 不要用 `!limited`;⑥**`nextResetAt`＝被限視窗全部解除之時刻＝被限視窗 `resetsAt` 之最晚者**(issue 原寫「最早者」:同時被限的多視窗須全部重置才恢復,取最早者會在其餘視窗仍被限時誤判可用);被限視窗中任一缺 `resetsAt` 或無法解析時為 `null`,無被限為 `null`;此為依狀態語意之推論,**未撞限實測**;⑦失敗分類沿用 `fetchQuotaJson`(`params`／`auth`／`forbidden`／`ratelimit`／`http`／`parse`／`timeout`／`network`／`toolarge`)加 `other`(內部未預期例外);403 且本文為 `EntitlementError`／「Go subscription required」時另帶 `noGoSubscription:true`(其餘一律 false);失敗結果含 `code`(HTTP 狀態碼,未收到回應為 `null`)、`provider`、`source`;⑧金鑰不印、不寫、不入結果:只經 Authorization 標頭送出;對端回顯之金鑰經 `redact` 遮蔽;金鑰須 6 字元以上之可見 ASCII 且無空白(過短者遮蔽規則不處理,含空白令標頭非法而使 fetch 訊息夾帶金鑰),否則 `params` 且不發請求;函數不寫日誌;⑨永不 reject(含 `opt` 為 null／非物件／已撤銷之 Proxy);⑩`baseURL` 非 http(s) 網址者視為未給、改用預設官方網址(dspec〈輸入參數之檢測機制〉K3:opt 鍵之非預期輸入改用預設,只有必須參數 `key` 報錯;`params` 訊息依 V19「invalid opt.key: must be …」、固定詞彙不回顯值),金鑰會送往該主機(JSDoc 警示);⑪**遞補層本輪不接用量**(不加條目 `quota` 欄位):Go 到頂時 `opencode run` 之行為未查明(免費池到頂時 run 不結束),查明前接入可能令每次嘗試耗滿 `timeoutMs`;若日後查明,接點宜為「冷卻判定時查一次,`limited` 即冷卻至 `nextResetAt`」,需另裁示.
